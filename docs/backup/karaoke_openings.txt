# 私人K歌台 · 开场台词
#
# 用法：放到 U 盘根目录（和 karaoke.conf 同一层），文件名 karaoke_openings.txt。
#       文件在，播歌时就会在歌词左边浮出这首歌的台词；文件删掉就一句都不显示。
#       台词只在直播模式按节目单顺序显示；普通模式不显示台词。
#       # 键（双击）用于切换 普通 / 直播 模式，不再管台词显隐。
#
# 格式：一行「## 歌文件名」开头，下面几行是台词，一行一段。
#       歌文件名不带 .mp3 / .lrc，要和 U 盘里的歌一模一样；
#       文件名统一不带序号；万一还带 02- 这类前缀，程序会自动再比一次。
#       「#」开头但不是「##」的行是注释。
#
# 每首 3-4 句、七八十个字，慢慢念差不多二三十秒；改词不用重装 App，
# 存好插回电视、重启 App 就生效。

## 茉莉花
家人们，说到《茉莉花》，相信大家都非常熟悉。这首歌旋律清新优美，唱出了茉莉花的洁白、美丽和清香，也展现了中国传统民歌独有的韵味。小小的一朵茉莉花，给人一种清新、淡雅的美好感觉。接下来我用电子琴弹一首《茉莉花》，希望这优美的旋律能带给大家一份好心情！

## 来与不来我都在等你
家人们，时间过得真快，又到了下播时间了。感谢大家今晚来到直播间，陪我一起听歌、聊天。虽然直播要结束了，但这份缘分和情谊还在。来与不来，每天晚上6:30我都在这里等着大家。希望大家每天过得开开心心，平平安安。最后，我把这首《来与不来我都在等你》送给直播间的每一位家人，期待我们明天再相聚！
